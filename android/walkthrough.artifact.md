# حل مشكلة تسجيل المكون (main registration fix)

تم تعديل طريقة تشغيل التطبيق لضمان التوافق التام مع Expo و Android.

## التغييرات التي تمت

### [index.js](file:///C:/Users/mohamed/Desktop/liofy/index.js)
تم استبدال `AppRegistry` بـ `registerRootComponent` من مكتبة `expo`.
هذا التغيير يضمن:
1. تسجيل التطبيق بالاسم الصحيح (`main`) تلقائياً.
2. تجهيز بيئة Expo (مثل الـ Native Modules) قبل بدء تشغيل الواجهة.
3. تجنب أخطاء "Invariant Violation" التي تحدث بسبب تأخر تحميل الكود.

## الخطوات التالية (هام جداً)

للتأكد من أن التغيير اشتغل، لازم تعمل الخطوات دي بالترتيب:

1. **قفل الـ Metro Bundler** (الشاشة السوداء اللي شغالة في الخلفية).
2. **تنظيف الكاش** وتشغيل التطبيق مرة تانية بالأمر ده:
   ```bash
   npx expo start -c
   ```
3. **إعادة بناء التطبيق** (لو لسه المشكلة موجودة):
   ```bash
   npx expo run:android
   ```
